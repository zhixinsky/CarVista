# CarVista

为 CarPlay 更换自定义壁纸，支持 **iOS 27 及以上版本**，专为**别克大连屏**适配。

别克大连屏内置 **9 张预裁剪超宽壁纸**，约 **3.65:1**，选中即可应用。使用自己的照片时，也可以在裁剪页选择 **3.65:1（别克）**，拖动裁剪框对齐车机画面。

## 功能

- **壁纸**：从相册单选照片，或使用别克大连屏专用壁纸。裁剪支持横屏预览、放大查看、四边自由裁剪和逐像素微调，也提供 16:9、3:4 和别克比例。导出保留裁剪区域的原始像素尺寸。
- **图库**：浏览 Bing 每日壁纸与历史图片，下拉刷新，滑到底部加载更多。选中图片后点「用作壁纸」，即可回到壁纸页继续调整或应用。
- **壁纸工具**：在壁纸页右上角查看历史记录、浏览车机壁纸缓存，或只生成壁纸文件。
- **设置**：查看使用指南与安装诊断，管理备份和恢复。

## 下载与安装

1. 打开 [GitHub Actions · Build CarVista IPA](https://github.com/zhixinsky/car/actions/workflows/ios-diagnostics.yml)。
2. 选择一次成功的构建，在 **Artifacts** 下载 **CarVista-resign**，解压得到 IPA。仓库维护者也可以手动运行 **Run workflow** 构建。
3. 使用支持有效 **App Group** 的签名方式重新签名并安装。选图、裁剪和本地生成可以离线使用，读取和替换 CarPlay 缓存需要相应的签名与访问条件。

## 更换壁纸

1. 停车后连接 CarPlay，在车机的 **设置 → 壁纸** 中切换一张内置图片壁纸，让系统产生缓存。
2. 打开 CarVista 的「壁纸」，从相册或内置壁纸选图，也可以从「图库」导入 Bing 图片。按需点「调整」裁剪。
3. 点「应用当前照片」，选择要替换的车机壁纸。App 会准备深浅色文件并在替换前备份原文件。
4. 如果车机仍显示旧图，重启 iPhone 后重新连接 CarPlay。需要还原时，打开 **设置 → 备份与恢复**。

## 兼容性

已有 **iPhone 16 Pro Max / iOS 27.2** 的车机壁纸替换反馈。别克大连屏的预裁剪壁纸和 **3.65:1** 预设按超宽 CarPlay 画面设计。实际显示及接缝效果会随车型、车机固件和 CarPlay 布局而变化。
